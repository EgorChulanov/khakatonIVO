# Хакатон ИВО 2026 · номинация «Анализ данных»

**Вопрос:** что сильнее связано с желанием бросить аспирантуру: внешняя нагрузка (работа, семья, финансы) или академическая среда, научное руководство и ментальное здоровье?

**Данные:** Всероссийский опрос аспирантов, 2021 (N = 5 007, 249 вузов). Зависимая переменная: Q13_r3 «Я часто хочу бросить обучение в аспирантуре».

## Главное

- Тип занятости почти не меняет риск (20–24% хотят уйти), вклад в объяснённую вариацию < 2%.
- Удовлетворённость руководителем, академическая принадлежность и депрессивные симптомы (PHQ-8) дают ~2/3 объяснённого; ROC AUC 0.83 против 0.61 у «внешних» факторов.
- 14–17% эффекта руководителя и среды проходит через ментальное здоровье.
- Принадлежность к кафедре сильнее защищает тех, кто работает полный день вне вуза.
- Связка с МЭВ (85 вузов): в вузах с высокой долей защит сотрудников за год аспиранты чаще хотят уйти (ОШ 1.30), устойчиво без крупнейших вузов.
- 4 типа аспирантов (k-means): риск от 5% до 59%, доля работающих везде ~45%.
- Репликация на студентах: начало работы между волнами не повышает мысли об уходе (ОШ 0.87, p = 0.65); решает переживание конфликта.
- Симуляция мер (g-computation): комплекс «встречи + сообщество + психологическая помощь» снижает долю желающих уйти на ~7 п.п.; уход с работы: 0.

## Структура

| Путь | Что внутри |
|---|---|
| `analysis/prep.py` | Подготовка переменных |
| `analysis/run_analysis.py` | Модели, Шепли, медиация, модерация, графики |
| `analysis/link_mev.py` | Сопоставление вузов опроса с МЭВ-2022 |
| `analysis/advanced.py` | Многоуровневая модель, бустинг, профили, симуляции, E-value, PSM |
| `analysis/replicate_students.py` | Репликация на лонгитюде студентов (3-й массив) |
| `analysis/calculator_model.py` | Компактная модель для калькулятора риска |
| `deck/risk_calculator.html` | Интерактивный калькулятор для защиты |
| `docs/defense.md` | Сценарий защиты, вопросы жюри, чек-лист сдачи |
| `deck/build_deck.js` | Сборка презентации (10 слайдов) |
| `output/` | Агрегированные результаты, графики, `.pptx` |

## Как воспроизвести

```bash
pip install pyreadstat pandas statsmodels scikit-learn matplotlib
ASP_SAV=/path/to/Аспиранты_массив.sav python3 analysis/run_analysis.py
ASP_SAV=... MEV_XLSX=/path/to/Мониторинги_массив_МЭВ.xlsx python3 analysis/advanced.py
npm install pptxgenjs
PPTX_SKILL=<путь к pptx-скиллу с scripts/apply_theme.js> node deck/build_deck.js
```
